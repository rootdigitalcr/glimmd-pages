# Glimmd — Markdown Reader for Chrome

This repository contains the public website, privacy policy, and support pages for **Glimmd**, a Chrome extension created by [Root Digital CR](https://root-cr.com/).

It does **not** contain the Glimmd extension source code.

## Public pages

- [Website](https://rootdigitalcr.github.io/glimmd-pages/)
- [Privacy policy](https://rootdigitalcr.github.io/glimmd-pages/privacy.html)
- [Support](https://rootdigitalcr.github.io/glimmd-pages/support.html)
- [Public support tracker](https://github.com/rootdigitalcr/glimmd-pages/issues)
- [Español](https://rootdigitalcr.github.io/glimmd-pages/es/)

Glimmd includes eight reading themes—Light, Dark, Sepia, System, Midnight, Forest, Slate, and High Contrast. It processes Markdown documents locally and does not include analytics, accounts, advertisements, or developer telemetry.
