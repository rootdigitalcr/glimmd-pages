# Glimmd — Markdown Reader for Chrome

This repository contains the public website, privacy policy, and support pages for **Glimmd**, a Chrome extension created by [Root Digital CR](https://root-cr.com/).

It does **not** contain the Glimmd extension source code.

Glimmd includes eight reading themes—Light, Dark, Sepia, System, Midnight, Forest, Slate, and High Contrast—plus persistent local highlights and comments, a local comment explorer, validated annotation backups, and reading-position recovery for recently opened documents. It processes Markdown documents locally and does not include analytics, accounts, advertisements, or developer telemetry.

To read local Markdown files, users enable **Allow access to file URLs** once in Glimmd's extension details, then drag a `.md` file into Chrome or open it with `Ctrl+O`. Glimmd also includes a bilingual Help and Getting Started page that checks this permission and explains the essential features.
