Read local Markdown files

  1. Open chrome://extensions, find Glimmd, and choose Details.
  2. Enable Allow access to file URLs. Chrome requires this explicit choice; Glimmd cannot enable it for you.
  3. Drag a .md file into Chrome or use Ctrl+O.
  4. If the tab was already open after installation, an update, or a permission change, reload it once.

The extension's Help and getting started page checks the current access state and explains navigation, search, appearance, shortcuts, and common problems.

Highlights, comments, and file changes

Select up to 500 characters and use the floating menu to highlight or comment on the passage. You can also add a comment to an existing highlight, or highlight a saved comment's passage directly from its editor without selecting it again. Both types stay in the local Chrome profile and appear in document order in separate right-panel tabs. Preferences shows their approximate storage, explores saved comments by text or document, and can back up or delete one, several, or all documents. When a file changes, Glimmd restores only unambiguous matches. Unmatched passages remain under Previous version so they can be copied or deleted; Glimmd never guesses a new location.

Resume reading

Glimmd remembers an approximate reading point for up to 120 recently opened documents and adapts it to the current window size when the document is opened again. This limited record stays in the local Chrome profile and expires after one year.

Before reporting a problem

  1. Confirm that Chrome 122 or newer is installed.
  2. For local documents, enable “Allow access to file URLs” on Glimmd's extension details page.
  3. Reload both the extension and any Markdown tab that was already open.

Include

Include the Glimmd and Chrome versions, operating system, steps to reproduce, expected result, and a minimal sample without private content. Do not send private documents, passwords, tokens, or personal file paths.
