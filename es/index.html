Lector Markdown para Chrome

Lee Markdown sin distracciones.

Glimmd convierte los documentos Markdown abiertos en Chrome en una vista clara con índice, navegación por carpeta, ocho temas, búsqueda, resaltados y comentarios locales persistentes, recuperación del punto de lectura, copia completa del texto y tipografía personalizable.

El procesamiento ocurre localmente. Glimmd no tiene analítica, cuentas, anuncios ni telemetría del desarrollador.

Archivos locales: abre los detalles de Glimmd, activa “Permitir acceso a URL de archivo” y arrastra un archivo .md a Chrome o ábrelo con Ctrl+O. Este permiso no se usa para Markdown web. Ver la guía rápida.
