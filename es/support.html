Leer archivos Markdown locales

  1. Abre chrome://extensions, busca Glimmd y entra en Detalles.
  2. Activa Permitir acceso a URL de archivo. Chrome exige esta decisión para abrir documentos guardados en tu equipo y detectar otros Markdown de la misma carpeta. Los Markdown web no necesitan este permiso.
  3. Arrastra un archivo .md a Chrome o usa Ctrl+O.
  4. Si la pestaña ya estaba abierta después de instalar, actualizar o cambiar el permiso, recárgala una vez.

La página Ayuda y primeros pasos de la extensión comprueba el estado actual y explica navegación, búsqueda, apariencia, atajos y problemas comunes.

Resaltados, comentarios y cambios del archivo

Selecciona hasta 500 caracteres y usa el menú flotante para resaltar o comentar el fragmento. También puedes agregar un comentario a un resaltado existente o resaltar directamente el fragmento de un comentario guardado desde su editor, sin seleccionarlo de nuevo. Ambos tipos permanecen en el perfil local de Chrome y aparecen ordenados en pestañas separadas del panel derecho. Preferencias muestra su almacenamiento aproximado, permite explorar comentarios guardados por texto o documento y puede respaldar o borrar uno, varios o todos los documentos. Si el archivo cambia, Glimmd solo recupera coincidencias inequívocas. Los fragmentos no asociados quedan en Versión anterior para copiarlos o eliminarlos; Glimmd nunca adivina una ubicación nueva.

Retomar la lectura

Glimmd recuerda un punto de lectura aproximado para un máximo de 120 documentos recientes y lo adapta al tamaño actual de la ventana cuando se vuelve a abrir el documento. Este registro limitado permanece en el perfil local de Chrome y caduca después de un año.

Antes de informar

  1. Confirma que usas Chrome 122 o posterior.
  2. Para documentos locales, activa “Permitir acceso a URL de archivo” en los detalles de Glimmd.
  3. Recarga la extensión y cualquier pestaña Markdown que ya estuviera abierta.
