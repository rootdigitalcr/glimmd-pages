Markdown Reader for Chrome

Read Markdown without distractions.

Glimmd turns Markdown documents opened in Chrome into a clean reading view with an outline, folder navigation, eight themes, search, persistent local highlights and comments, reading-position recovery, full-text copying, and customizable typography.

Document processing happens locally. Glimmd has no analytics, accounts, advertisements, or developer telemetry.

Local files: open Glimmd's extension details, enable “Allow access to file URLs,” then drag a .md file into Chrome or open it with Ctrl+O. See the quick guide.
