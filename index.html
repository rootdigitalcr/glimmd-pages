Markdown Reader for Chrome

Read Markdown without distractions.

Glimmd turns Markdown documents opened in Chrome into a clean reading view with an outline, folder navigation, eight themes, search, and customizable typography.

Document processing happens locally. Glimmd has no analytics, accounts, advertisements, or developer telemetry.
